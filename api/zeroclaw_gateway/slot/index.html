Dashboard slot REST types.

The core data model (Slot, SlotAgentConfig, SlotState, SlotMode, SlotStore) lives in zeroclaw-infra so both the gateway and the storage backend can use it without a dependency cycle. This module re-exports those types and adds request/response wrappers with #[derive(schemars::JsonSchema)] so the OpenAPI generator can describe /api/slots endpoints.

Behind the schema-export feature, JSON Schema derives are enabled; without it the wrappers remain plain serde types. This mirrors the api_config pattern.
