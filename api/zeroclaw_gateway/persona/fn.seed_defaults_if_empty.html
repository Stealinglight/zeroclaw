pub fn seed_defaults_if_empty(workspace_dir: &Path) -> Result<bool>

Seed the four default presets when the personas dir is empty or missing. No-op when any persona already exists. Callers should invoke this from GET /api/personas so the dashboard’s first request gets a populated dropdown without explicit user setup.
