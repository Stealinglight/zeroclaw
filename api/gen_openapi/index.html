cargo xtask gen-openapi — render the gateway’s OpenAPI 3.1 spec in process and write it to the committed snapshot at crates/zeroclaw-gateway/openapi.json.

  • No flags: overwrite the snapshot with the current in-process spec.
  • --check: render to a string and diff against the committed snapshot. Exits non-zero on drift and prints the first 80 lines of unified diff.

Wired into CI via ./dev/ci.sh so any handler change that forgets to re-run this step fails review rather than silently diverging.
